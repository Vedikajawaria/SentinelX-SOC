# 🛡️ SentinelX

### AI-Powered SOC Detection & Response Platform

SentinelX is an AI-powered Security Operations Center (SOC) platform designed to analyze network traffic and detect potentially anomalous network flows using machine learning.

The platform uses an **Isolation Forest-based anomaly detection engine** to identify unusual network traffic and presents the results through an interactive Streamlit SOC dashboard.

---

##  Features

- 🤖 AI-based network anomaly detection
- 🌐 Network traffic analysis
- 🚨 Automated anomaly detection
- 📊 SOC Executive Summary dashboard
- 📈 Network traffic analytics
- 🔥 Threat and anomaly statistics
- 🧠 Isolation Forest anomaly detection
- 📋 Security log monitoring
- 🔍 Anomaly investigation
- 📉 Anomaly score analysis
- 📊 Visual SOC dashboard using Streamlit
