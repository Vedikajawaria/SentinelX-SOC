# 🛡️ SentinelX

## AI-Powered SOC Detection & Response Platform

SentinelX is an AI-powered Security Operations Center (SOC) platform that collects security logs, detects cyber threats using machine learning, correlates security events, and provides intelligent incident response through an interactive dashboard.

### Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- Plotly
- SQLite
